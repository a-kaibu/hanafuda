# 札画像の出典とライセンス

`assets/cards/alt/` の札画像は Wikimedia Commons の花札 SVG（伝統的な配色・黒枠版）です。ゲームのコードとは別に、各画像は以下の作者による **[Creative Commons 表示-継承 4.0 国際 (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/deed.ja)** で提供されています。

- 作者: Louie Mantia（原画）、すけじょ（伝統配色・黒枠版への改変）、Spenĉjo（裏面）。ファイルごとの表記は下の表のとおり
- 取得元: https://commons.wikimedia.org/wiki/Category:SVG_Hanafuda_with_traditional_colors_(black_border)
- 改変: なし（ファイル名をゲーム内の札番号に変えて保存しています）
- 取得方法: `tools/commons_download.py`（GitHub Actions の `Commons card art download` ワークフロー）。各ファイルの作者・ライセンスは Commons の API から取得し `credits.json` に記録しています。
